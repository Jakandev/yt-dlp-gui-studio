Engines

Updating yt-dlp never touches the interface or the site support built into this app — those live inside the app itself. Your settings, queue and history are untouched too.

Your data

This install keeps everything in %APPDATA%\yt-dlp Studio — queue, history, settings, cookies and thumbnails. It survives app updates, reinstalls and uninstalling.

Backup & restore

Save every setting — plus your saved site cookies — into one file, so a new Windows install or a reinstall can get back to the same setup in one click. Download history and the queue are not included.

About

yt-dlp-GUI Studio App — a desktop interface for the yt-dlp downloader engine. All downloading is done by the bundled yt-dlp binary; this app only drives it.
